## 实现边界

- KeyboardTest 是自己的静态测试模块；KBeditor 是用户明确要求的辅助 EXE。二者各自维护解析、窗口、捕获和状态，不新增共享业务库，不依赖其他测试模块。
- 普通键按扫描码及 extended 位识别，以完整按下/松开为一次操作；自动重复不另计。Pause 没有正常松开事件时按 Windows 已知单次按下语义处理。
- Copilot 使用显式组合键记录，完整组合匹配且组成事件结束才通过一个键，不把参与组合的 Shift/Windows/C/F23 计为其他配置键的通过。20 ms 相邻按键检查只处理普通键，不将组合内部事件判为连键。无法通过这些事件区分物理 Copilot 与人工按出的完全相同组合。
- Retest 清空计数与输入状态；失焦暂停捕获，恢复时必须重新按键。Esc 可以是被测按键，不作为退出快捷键。全部配置键通过自动 PASS；操作员结束/关闭 FAIL；宿主停止 CANCEL；无新增总超时。
- 输入钩子仅在本测试窗口或编辑器捕获窗口处于前台时拦截，回调只暂存事件与投递合并通知。窗口清理后释放钩子再报告终态，后台布局读写不得操作已销毁窗口。

## 配置与交付

配置使用 IniEditor 编辑加密的 config.ini，保存后重启主程序。默认不新增启用项，原有工站配置保持原样；启用时添加：

```ini
[TestItem]
KeyboardTest=1
[KeyboardTest]
LayoutFile=ExternalTools\Main.KBL
[DisplayName.zh-CN]
KeyboardTest=键盘测试
[DisplayName.en-US]
KeyboardTest=Keyboard Test
[DisplayName.vi-VN]
KeyboardTest=Kiểm tra bàn phím
```

LayoutFile 缺省使用 `ExternalTools\Main.KBL`，相对路径以 config.ini 的目录为基准，节名/键名与 Culture 不区分大小写；未知配置键忽略。布局是本次测试的只读快照，运行中编辑文件不改变正在进行的测试。

`build-release.ps1` 更新正式 `package\TestCases.exe`、历史、离线手册以及 `package\ExternalTools\KBeditor.exe`。仅在 Main.KBL 不存在时安装参考的 13 键样例，绝不覆盖工站已有布局。生产键盘应通过编辑器配置全部实际需测试的按键，样例不代表完整键盘。

## KBL 兼容格式

普通布局保持原始四字段头与七字段按键行。文本支持 UTF-8、带 BOM 的 UTF-16LE 和旧系统 ANSI；编辑器写入 UTF-8，临时文件成功写入并刷新后才替换目标文件。

包含组合绑定或零扫描码的虚拟键绑定时，首行使用 `KBL2][数量][外框宽][外框高][StickFlag`；每行保留原七字段，再追加 `Single/Chord` 与 `扫描码,extended位,虚拟键+…`。组合成员数为 2–8。新测试/编辑器均读两种格式；旧工具不能读取 KBL2，明确拒绝新头，避免只测一个组成键就通过。

编辑器按用户最终要求默认空白，不自动打开 Main.KBL；“打开 KBL”加载现有布局。也可显式指定文件参数和 `--language zh-CN/en-US/vi-VN`。

- 点一次“连续添加”，逐个按下并松开实体键；仅点击鼠标“下一行”才换行，超出当前宽度时横向扩展布局并缩放显示。到达 KBL 最大宽度 16384 时提示手动换行，不自动把按键移到另一行。“停止录入”保留已加入的按键。同一绑定再次录入只选中已有按键。重叠按下的多个键记录成一个组合，普通键应逐个松开。
- 鼠标拖动移动按键，直接拖动选中按键右下角调整尺寸，双击按键后按实体键重新绑定；方向键移动，Ctrl+方向键调整尺寸。
- 常用面板只显示名称、实际绑定和操作按钮。位置、尺寸、扫描码、extended、布局尺寸和 20 ms 开关收进可滚动的“详细属性”。组合绑定通过重新捕获修改，扫描码字段不把整组降为单键。
- 支持撤销/重做（Ctrl+Z / Ctrl+Y）、Ctrl+N 新建、Ctrl+O 打开、Ctrl+S 保存；文本输入框内保留自己的撤销。保存、切换文档和退出前应用当前属性；有未保存修改时提供保存/不保存/取消。
- “预览测试”直接在编辑器内检验当前布局，不查找旧 kbtest.exe；鼠标停止后返回编辑。布局显示使用固定页面坐标，拖动期间不重新缩放，避免按键跟随鼠标时跳动。
- 默认保存位置为编辑器所在目录，即正式包 ExternalTools；新建空白必须添加至少一个按键才能保存。文件读写在后台执行，保存采用校验和临时文件替换。

## Copilot 与输入限制

- 捕获时按下并松开目标机的实体 Copilot 键，保存实际事件；不把所有名为 Copilot 的按键绑定到一个固定扫描码，也不把孤立 F23 默认当作 Copilot。
- 组合事件与手动按出的同一组合无法仅凭键盘钩子区分；首版不限定输入设备，沿用旧工具的系统键盘事件来源。测试证明输入路径，不能证明 Copilot 应用启动或设备来源。
- 仅测试窗口/捕获编辑器在前台时拦截，离开时暂停并撤销尚未完成的按下状态；返回后须松开、重新按键。Ctrl+Alt+Del 等系统保留组合和仅由固件处理的 Fn 不属于可保证捕获的键。
- 每个普通键完整按下/松开通过一次，自动重复不额外计数；Pause 按 Windows 的按下事件处理。全部配置键通过自动 PASS，End test/关闭 FAIL，宿主停止 CANCEL，无总超时。
- StickFlag 非零保留 20 ms 相邻普通键重试模式；组合内部不判连键。Retest 清空结果、按下记录、前键与时间，不保留负数计数。
