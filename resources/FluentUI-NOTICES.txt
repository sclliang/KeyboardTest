# Third-party notices

The native TimePlot/RealTimePlot examples follow the demo settings and interactions
in zhuzichu520/FluentUI. Their rendering, data storage and input handling are
implemented in this SDK; Qt and QCustomPlot are not linked or redistributed as
part of the native SDK or Gallery.

The native C++/Direct2D implementation reproduces the behavior and appearance of
[zhuzichu520/FluentUI](https://github.com/zhuzichu520/FluentUI), reference commit
`7e33a2f672d18239ef49ab960075b1137a1d18e7`. Ported style definitions retain the
repository's MIT notice below. Reused assets can carry their own notices and terms,
including the Microsoft font listed separately here. Qt is not linked into this library.
Additional third-party assets and libraries will be recorded here when incorporated.

## zhuzichu520/FluentUI

The native Squircle shader ports the fixed example's `OpenGLItem.cpp` fragment
formula and framebuffer blend. Its Gallery loop follows `T_OpenGL.qml`.
These definitions retain the MIT notice below. The separate Qt source observer
is diagnostic tooling and is not linked into the distributed native SDK.

The Gallery translation catalog is generated from the pinned example's
`example/example_zh_CN.ts`. It retains 542 active, nonempty context-specific
translations, excluding obsolete entries. The source hash and generation method
are recorded in `examples/resources/translations`. This data uses the repository
MIT notice below and is embedded only in the Gallery example, not the SDK library.

## T_Clip avatar and banner assets

Source: `zhuzichu520/FluentUI`, fixed commit
`7e33a2f672d18239ef49ab960075b1137a1d18e7`, files
`example/res/svg/avatar_1.svg` through `avatar_4.svg` and
`example/res/image/banner_1.jpg`. The Gallery embeds twelve direct rasterizations
of those SVGs at 50/75/100 pixels and the unchanged original JPEG. Original source
bytes and the upstream repository notice are retained under
`examples/resources/shapes/source`; per-source/output SHA-256 records are in
`examples/resources/shapes/source-manifest.json` and `banner-source.json`.
The optional static Qt 6.8.4 conversion tool is used offline only; no Qt library
or plugin is part of the native Gallery or SDK. This provenance record does not
replace any separate notices carried by the original assets.
